# Job Portal

A responsive job portal web application developed as a team project
to connect job seekers with recruiters.

## Features

- Job listings and search
- Job filtering
- Recruiter dashboard
- Application management
- Responsive user interface
- Navigation using React Router

## Tech Stack

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- REST APIs

### Services & Integrations
- Clerk — Authentication
- Cloudinary — Image/File Management
- Sentry — Error Monitoring
- Webhooks — Event-based communication/integration
